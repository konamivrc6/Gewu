# 格物

> 在一块 8×8 点阵上，渲染几颗**有物理的像素**。

---

## 硬件

| 器件 | 作用 |
|---|---|
| 合宙 CORE-ESP32-C3 | 主控，跑物理引擎 |
| MAX7219 + 8×8 点阵 | 世界本身 |
| MPU6500 | 重力矢量来源 |
| 旋转编码器 EC11 | 连续量输入——重力系数、弹性、阻尼、时间步长 |
| 微动开关 ×2 | 离散量输入——重置、生成、暂停 |
| SN74HCT125 | 3.3V → 5V 电平转换，驱动 MAX7219 |
| 拨动开关 + 2pin 排针 | 5V 供电入口 |

**`PCB/` 里的 EDA 工程仍标 MPU6050——那只是因为立创EDA 元件库里有这一颗，实际按 MPU6500 采购。**

**完整接线见 [`硬件接线.md`](硬件接线.md)。** 该文档包含经官方资料核实的引脚分配、电平转换细节、去耦要求与上电检查步骤，动烙铁前请通读。

---

## 设计要点

**为什么需要 SN74HCT125**：MAX7219 在 5V 供电时输入高电平门限为 3.5V，而 ESP32-C3 输出仅 3.3V，处于「有时能用有时不能用」的危险区间。HCT 系列是 TTL 电平输入，2.0V 即判为高，3.3V 驱动有充足余量，输出 5V 摆幅正好匹配。它只能单向使用，因此**不能**用于传感器的 I2C 总线。

**为什么 X 放在 Y 引脚**：见接线文档「主控引脚分配」一节，其中 GPIO8 与 strapping 脚的取舍有专门说明。

## 软件栈

- 平台：Arduino（板型 `AirM2M CORE ESP32C3`）或 ESP-IDF
- 构建：`arduino-cli compile firmware/Hardware_Test`。板型、平台与库版本都钉在 `firmware/Hardware_Test/sketch.yaml` 里，缺什么会自动下载，换机器不必先配板管理器
- flash 模式：DIO（本板型固定，无需设置）
- 显示驱动：MAX7219 三线协议，3 个 GPIO
- 传感器：MPU6500 I2C，地址 `0x68`。九个标定常数（加速度计六个、陀螺三个）与「模组系 → 屏幕系」的轴映射都在固件里，来历见 [`标定.md`](标定.md)
- 物理引擎：自写，1-bit 离散世界，无需浮点库

## 工具

`tools/` 下的脚本分两拨。

**工程包解析**——只依赖标准库，**都不传参数即可裸跑**——默认取 `PCB/` 下最新的 `.epro2`，免得工程一改名就集体失效。

| 脚本 | 作用 | 用法 |
|---|---|---|
| `bom.py` | 元器件清单：位号明细、按立创编号聚合的采购表、PCB 手焊清单 | `python tools/bom.py` |
| `netlist.py` | PCB 网表，按位号列出每个焊盘的网络，用来对照 `硬件接线.md` | `python tools/netlist.py` |
| `epro_dump.py` | 工程文件概览：元素类型计数与文档段划分 | `python tools/epro_dump.py` |

`bom.py` 另有两个开关：`--json` 出结构化数据，`-o 文件` 写进文件。**要重定向就用 `-o`**——PowerShell 的 `>` 默认产出 UTF-16，别的工具读不了。

手焊清单的「标签」不是位号，是 layout 阶段为了手焊方便在板面上改成的展示值（`100nF`、`4k7`、`HCT125`），脚本照读原值，并附上它对应的权威位号，方便回头查原理图。

**台面调试与标定**——要 `pyserial`，要板子插在串口上，默认端口 `COM11`（换端口加 `--port`）。三支都按 921600 打开。**默认不复位**——只有加 `--reset` 才拉 RTS 让板子重启，因为复位会冲掉亮度、显示模式、屏上已画的内容，而标定过程往往正需要保留这些。

| 脚本 | 作用 | 用法 |
|---|---|---|
| `serial_send.py` | 逐条发串口命令并回显，滤掉 IMU 数据行，`--reset` 会等开机横幅 | `python tools/serial_send.py '?' 'i 8'` |
| `imu_stat.py` | 抓一段 IMU 数据行做静止统计：均值、原始计数、标准差、模长、重力方向 | `python tools/imu_stat.py --sec 12 --label '点阵面朝上'` |
| `accel_calib.py` | 加速度计六面标定：`record` 采一个姿态、`status` 看还缺哪个、`solve` 解常数并自检 | `python tools/accel_calib.py record --pose flat_up` |

原始数据写到 `%TEMP%`，不进仓库。判据、摆法与固件那一路串口命令的清单都在 [`标定.md`](标定.md)。
